## Fehler & Learnings

**Learning 1:** Sunk Cost Fallacy
- Stundenlang Lineup Builder investiert → Gefühl "muss fertig werden"
- Verbesserung: Requirements First - am Anfang klären was gefordert ist

**Learning 2:** Feature Creep
- Von Prediction-Display zu Drag & Drop System
- Verbesserung: YAGNI (You Aren't Gonna Need It)

**Learning 3:** String-Replace Overuse
- 90+ Tool-Calls für lineup-builder Änderungen, Datei korrupt
- Verbesserung: Bei grossen Umstrukturierungen lieber neu schreiben

**Learning 4:** Race Condition übersehen
- Bank Overflow: Check BEVOR State-Update
- Verbesserung: Future-State Pattern - immer `future = current + delta` berechnen VOR Update

**Learning 5:** Git Checkout ohne Prüfung
- `git checkout HEAD --` ohne zu prüfen
- Verbesserung: Immer `git show COMMIT:path` vor Checkout

**Learning 6:** Zu viele temp-Dateien committed
- Hätte mehr auf .gitignore achten sollen
- Verbesserung: .gitignore und Struktur ZUERST beim nächsten Projekt

Technische Erkenntnisse:
- DragOverlay: dropAnimation=null, transformOrigin '0 0'
- CSS line-clamp + flex: Incompatibel
- PlayerCard: shrink-0 für fixed-size in Flex
- Optimale UI-Grössen: 96px Avatare, 48px Icons, text-xl Namen
- PowerShell Move-Item -Force statt CMD move /Y

Workflow-Erkenntnisse:
- Bei korrupten Files: Backup + kompletter Rewrite
- create_file + Move sauberer als viele replace_string_in_file
- Grep-Validierung nach Farbänderungen
- Systematischer Cleanup mit Todo-Liste spart Zeit
