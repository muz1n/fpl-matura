# Beispiele

Dieser Ordner enthält **Demo-Skripte**, die zeigen, wie bestimmte Features funktionieren.

## Inhalt

### demo_bench_policy.py
- **Zweck:** Demonstriert die Bank-Policy (Bench-Auswahl) bei der Lineup-Optimierung
- **Verwendung:** `python docs/examples/demo_bench_policy.py`
- **Output:** Zeigt, wie die Bank-Spieler ausgewählt werden

### demo_format_lineup.py
- **Zweck:** Zeigt, wie Lineup-Formatierung funktioniert
- **Verwendung:** `python docs/examples/demo_format_lineup.py`
- **Output:** Formatierte Aufstellungs-Tabelle

## Hinweis

Diese Skripte sind **nicht Teil der Hauptpipeline**, sondern dienen nur zur Demonstration und zum Testen einzelner Features.
